# Distribution readiness

This is a private, local staging copy prepared for review. It has NOT been pushed to GitHub, uploaded to Melty, or published as a release.

## Status
Experimental development candidate: native ASI compilation and local package checks have passed, but the ASI has not been verified in GTA V gameplay and Melty's own validation/one-click checks have not been completed. The paired-launch draft is not proof of Spider-Man Remastered content integration.

## Before any release
- Verify the build from a clean checkout.
- Run the actual Melty recipe/package/one-click validation.
- Test in GTA V Legacy Story Mode only; never GTA Online.
- Capture genuine gameplay evidence and logs.
- Review third-party notices and confirm every redistributed component is permitted.
- Obtain the user's explicit final approval before creating/pushing a remote repository or uploading any release.

## Distribution boundaries
Do not include game executables, game archives, saves, extracted proprietary assets, third-party Spider-Man mod assets, local credentials, or local machine paths. The vendor folder in this staged repo is limited to the runtime sources and their licenses required to build this prototype; unrelated reference repositories and private draft archives are excluded.
